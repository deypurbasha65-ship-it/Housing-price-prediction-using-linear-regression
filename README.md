# 🏠 House Price Prediction using Linear Regression

## Project Overview

This project develops a **House Price Prediction** model using **Linear Regression** to estimate residential property prices based on structural, amenity, and location-related features. The objective is not only to predict house prices but also to identify the key factors that significantly influence property values through statistical analysis.

## Problem Statement

Accurately pricing residential properties is a challenging task due to the influence of multiple interacting factors such as house size, number of bathrooms, parking availability, air conditioning, and location. This project builds an interpretable regression model to provide data-driven pricing estimates and support informed decision-making for buyers, sellers, and real estate businesses.

## Dataset

* **Records:** 545 residential properties
* **Features:** 12 predictor variables
* **Target Variable:** House Price
* **Missing Values:** None
* **Duplicate Records:** None

## Project Workflow

* Data Cleaning & Validation
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Correlation & Multicollinearity Analysis (VIF)
* Linear Regression Modeling
* Model Evaluation (MAE, RMSE, R²)
* OLS Statistical Analysis
* Regression Assumption Testing
* Model Refinement
* Log Transformation
* Business Insights & Recommendations

## Key Highlights

* Performed comprehensive Exploratory Data Analysis (EDA).
* Applied feature engineering using binary and one-hot encoding.
* Evaluated multicollinearity using Variance Inflation Factor (VIF).
* Built and compared multiple Linear Regression models.
* Conducted statistical significance testing using Ordinary Least Squares (OLS).
* Validated regression assumptions using residual analysis, Q-Q plots, Breusch-Pagan Test, and Durbin-Watson Test.
* Improved model performance using log transformation.
* Converted analytical findings into actionable business recommendations.

The project provides a transparent and interpretable pricing framework that helps:

* Identify the most influential factors affecting house prices.
* Support pricing strategies for real estate companies.
* Assist investors in making data-driven property investment decisions.
